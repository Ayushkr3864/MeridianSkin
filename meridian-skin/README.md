# Meridian Skin Clinic

A modern, responsive dermatology and skincare clinic website built with **Next.js and React.js** as a frontend UI assignment.

The project focuses on creating a premium healthcare/wellness experience with a strong emphasis on responsive design, visual consistency, typography, spacing, accessibility, and user experience.

## 🔗 Live Demo

**Live Website:** https://meridian-skin.vercel.app/

## 📌 Project Overview

Meridian Skin Clinic is a fictional dermatology and skincare clinic website designed to provide users with an elegant and intuitive experience for exploring skincare treatments and booking consultations.

The design was inspired by modern dermatology, healthcare, beauty, and wellness websites, while maintaining an original brand identity, layout, color palette, content, and UI design.

> **Note:** This is a frontend concept/assignment project. Meridian Skin Clinic is a fictional brand and the statistics, testimonials, clinic information, and other content are for demonstration purposes only.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js 18+
* npm

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the project

```bash
cd meridian-skin
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

in your browser.

## 📦 Production Build

To create a production build:

```bash
npm run build
```

To run the production build locally:

```bash
npm start
```
